## Outcome and limits

Both C/G grammars are generated by Level L DFA/LR(1) services. Level B compiler
modules perform contextual token classification, source admission, G binding and
type propagation, Classic activation/context mapping, local/recursive and imported
call checking, and verified shared IR construction. The six paired source controls
all generate the retained [trees and IR](../../examples/step03/README.md).

Syntax regressions check message categories, useful expected tokens, exact byte
anchors, filename/line/Unicode-column reporting and refusal to publish a successful
graph. They include THEN/END, ELSE, operands, parentheses/calls, quotes/comments,
UTF-8/NUL, Unicode/CRLF and unsupported instructions. Semantic tests cover defaults,
exact literals, Boolean carriers, short-circuit versus eager lowering, calls,
omissions/RESULT, numeric contexts, selected actual import contracts and budgets.

The reusable service ends at checked IR. It does not yet emit executable C/G RXAS,
prove runtime equivalence of the new operations, implement production optimisation,
install replacement compilers, or execute INTERPRET. Those remain STEP04–10.
The native compiler still builds the B host; it is not used by source-to-IR
requests. No native compiler implementation was changed.

## Corrections retained in this increment

A new source-span assertion initially used the wrong boundary; Level L
nonterminal ranges include trivia up to the next token while literal spelling
is exact. The corrected permanent assertion verifies that documented boundary.
The expected failed development attempt is not included as a successful test.

Reviewing actual IR exposed missing named extension attributes in the readable
dump. It now shows pool keys and call targets as well as operands, with a generic
attribute regression. The lossless text/binary formats are unchanged.

That view exposed a real frontend defect: `NUMERIC /*one*/ FORM /*two*/
ENGINEERING` previously selected `FORM` by splitting the original instruction
text. The grammar now projects only the optional form-value rule; empty selects
SCIENTIFIC. The regression checks the selected ENGINEERING attribute and ARG
names separated by comments. Generic Level L cardinality checking rejected an
intermediate optional-capture spelling before it could generate an invalid
parser; the final grammar has an explicit value rule.
