cREXX LOTTO - WINDOWS INSTRUCTIONS

SOURCE CHECKOUT: BUILD BEFORE RUNNING

1. Install the Windows x64 cREXX 1.0.0 Beta 3 core package from:
   https://github.com/adesutherland/CREXX/releases/tag/v1.0.0-beta.3
   The signed setup EXE normally installs under C:\Program Files\CREXX.
   The separate optional llama/model downloads are not needed.

2. Fetch the transport branch into a clean CREXX checkout. Open Windows Terminal or
   Command Prompt. In Windows Terminal, choose the Command Prompt profile;
   the following commands use cmd.exe syntax, not PowerShell syntax.

3. Set the path to the installed BIN folder and enter the example folder:

     set "CREXX_BIN=C:\Program Files\CREXX\bin"
     cd /d "C:\src\CREXX\examples\franz-lotto\crexx"
     "%CREXX_BIN%\rxc.exe" -v

   The version should be exactly crexx-1.0.0-beta.3. If you used the core ZIP
   instead of the installer, CREXX_BIN must name its extracted bin folder,
   for example C:\Tools\CREXX-windows-x64\bin. Keep the whole cREXX package
   together: rxvm.exe needs the adjacent rxconsole provider and libraries.

4. No generated bytecode is committed on this source transport branch. Follow
   READING / REBUILDING THE SOURCE below first, including the model checks.
   Make the terminal at least 80 columns by 24 rows, then run:

     "%CREXX_BIN%\rxvm.exe" "lotto_app.rxbin"

CONTROLS

  The (*) marker shows the one selected game.
  Tab / Shift-Tab moves focus. With the game group focused, arrows change it.
  A / D / E, or 1 / 2 / 3, select Austria / Germany / Euro-Lotto.
  T focuses the numeric field. The first digit replaces the old value; a second
  digit appends. Backspace removes a digit; Delete clears the field.
  The numeric field accepts one or two digits; Generate validates 1-50.
  Enter in the numeric field generates; Enter on a button activates it.
  G generates. P / N or PageUp / PageDown views pages of eight tips.
  S saves, after a SECOND S to confirm replacement. Q quits.
  Letter shortcuts are inactive while editing the number; use Tab to leave it.
  Escape or Ctrl-C quits from anywhere. Normal exit restores the terminal.
  Mouse support is optional: a left press/release on the same control activates
  it. All operations remain available from the keyboard.

Results do not change until Generate. Invalid entry keeps the last results.
Changing the selected game does not relabel previously generated tips.
Save writes the COMPLETE result, including tips on other pages, to:

  Lotto-Tipps-cREXX.txt

in the example folder, replacing that file only after confirmation. If Save
fails, choose a writable example folder; the results remain on screen. Generate
and startup never write the output file. No editor is launched automatically.

READING / REBUILDING THE SOURCE

lotto_logic.crexx: typed, screen-independent game rules, validation and Save.
lotto.crexx: one procedural input loop plus pure ANSI screen rendering.
lotto_tests.crexx: model and file checks; separate from the interactive screen.

With CREXX_BIN set and the current directory still crexx, run EACH command in
order. Stop if any command reports an error. No C/C++ compiler or CMake is needed
for the ordinary ANSI example:

  "%CREXX_BIN%\rxc.exe" -o lotto_logic lotto_logic.crexx
  "%CREXX_BIN%\rxas.exe" -o lotto_logic lotto_logic
  "%CREXX_BIN%\rxc.exe" -o lotto lotto.crexx
  "%CREXX_BIN%\rxas.exe" -o lotto lotto
  "%CREXX_BIN%\rxlink.exe" -o lotto_app lotto lotto_logic "%CREXX_BIN%\library"
  "%CREXX_BIN%\rxvm.exe" lotto_app.rxbin

This exercises compiler, assembler, linker and VM. It uses Beta 3 APIs only.
There are no RXPP macros or extra UI modules to install.

AUTOMATED CHECKS

Build the checks below before running them. They use the same Lotto model
as the application:

  "%CREXX_BIN%\rxvm.exe" lotto_checks.rxbin

Expected: PASS: cREXX Lotto (3825 tips; validation, save, replace, failure)
The checks create/replace lotto-test-output.txt in this folder. They do not
modify Lotto-Tipps-cREXX.txt. The folder missing-lotto-folder must not exist;
it is deliberately used to exercise save failure.

To rebuild the checks after editing the model:

  "%CREXX_BIN%\rxc.exe" -o lotto_tests lotto_tests.crexx
  "%CREXX_BIN%\rxas.exe" -o lotto_tests lotto_tests
  "%CREXX_BIN%\rxlink.exe" -o lotto_checks lotto_tests lotto_logic "%CREXX_BIN%\library"
  "%CREXX_BIN%\rxvm.exe" lotto_checks.rxbin

TROUBLESHOOTING

"Cannot find...": recheck CREXX_BIN and the quoted example-folder path.
"Open a real terminal...": run in a foreground terminal, not an IDE output pane,
a redirected pipeline or a background task. Use an ordinary Command Prompt
window if a terminal host does not provide native console input.
Missing rxconsole: retain the complete Beta 3 installation, including bin and
its providers folder. Do not copy rxvm.exe on its own.
Resize message: enlarge the window/font viewport to at least 80x24.
For the optional GTK desktop version, read gui-provider/WINDOWS-BUILD.txt.
