## Vision and intended outcomes

Ordinary concurrent `crexx` invocations for the same source must safely own
their shared adjacent outputs, so each run uses a complete image and retains
the documented `--keep` and `--nokeep` behavior. Adrian approved lock-and-wait
for #705 on 2026-09-27. The driver should use the existing cross-platform
`rxfs.fileguard` facility, wait when another driver owns an output, and report
unavailable or expired locks without overwriting another process's files.
Project (`--program`/`--library`) mode has a separate output lifecycle and is
not claimed safe by this issue.

The llama qualification guide must distinguish compatible general profiles
from exact reference presets without broadening tested-model or platform
claims. The RXPP alias directive must emit its correct generated code without
the unconditional debug marker.

Published snapshot SDKs for Windows x64, macOS arm64 and macOS x86_64 must be
relocatable, identified by exact source revision and digest, and usable by a
fresh downstream native application without rebuilding CREXX or borrowing from
a source checkout or another installation. They must carry the installed CMake
exports/helpers/headers, native toolchain, core runtimes, and both forms of the
SQLite and vector providers. The matching llama runtime cohort may be a
documented same-revision overlay. Existing runtime archives and installers
must remain usable. RAG's source-built SDK control and hosted checks are
historical evidence, not proof of a new downloaded SDK.

The four repairs will be made in the order #705, #704, #706, #707. Each gets a
small relevant check. The final combined code/test/build tree gets one normal
correctness and packaging qualification, with hosted platform checks where
needed for the SDK. Ordinary development publication does not require manual
overnight assurance merely because these changes are batched.

## Numbered acceptance criteria

- **AC-01 [local pass; hosted open, #705]:** Concurrent ordinary invocations of the same source
  all exit successfully and print expected program output; a prebuilt RXBIN
  control also succeeds. Verify with a permanent process-concurrency regression
  plus focused local execution.
- **AC-02 [local pass; hosted open, #705]:** Shared output paths are acquired in a deterministic
  order before writes and retained through load/execution and cleanup. Normal,
  `--noexec`, `--nocompile`, `--keep`/`--nokeep`, multiple-source and RXPP
  paths preserve their observable output and cleanup contracts. Verify with
  focused driver tests and inspected ownership paths.
- **AC-03 [local pass; hosted open, #705]:** A busy guard waits without corrupting output; genuine
  acquisition error or configured wait expiry reports a clear nonzero result.
  Lock files remain stable across acquisitions and process death releases OS
  ownership. Verify with a held-lock control and cross-platform checks.
- **AC-04 [done, #704]:** `qualification.md`, `models.md` and `common.md`
  consistently admit compatible GGUFs/quantizations under general profiles,
  retain strict reference-preset hashes and greedy-sampling restriction, and
  make no new qualification claim. Verify by a focused document inspection.
- **AC-05 [macOS arm64 local pass; hosted open, #706]:** Exact-revision SDK ZIPs for the three named platforms
  contain BUILDINFO, digests, licences/notices, complete normal-install public
  headers, CMake config/exports/helpers, tools/runtimes, and static/dynamic
  SQLite and vector providers. Verify asset inventory and manifest hashes.
- **AC-06 [macOS arm64 local pass; hosted open, #706]:** A downloaded SDK works after relocation into a path
  with spaces: `find_package(CREXX CONFIG REQUIRED)` resolves without producer
  paths, and a native consumer builds/runs with installed SQLite and vector
  static providers. Verify isolated consumer probes on each platform.
- **AC-07 [open, #706]:** RAG builds using only the downloaded exact-version
  SDK, ordinary host tools and an explicitly documented matching llama
  runtime overlay, then passes its existing ZIP and installer smokes on all
  three platforms, including Windows install/reinstall/PATH/safe-uninstall.
  No model download or hosted provider call is required. Verify hosted
  downstream results and retain SHA/run references.
- **AC-08 [local pass; hosted open, #707]:** `##DALIAS` and equivalent `##DATA` preprocessing
  produce correct assignments; neither emits the internal `12345` marker.
  Verify a permanent focused RXPP regression in both optimization modes.
- **AC-09 [local pass; hosted open, batch]:** Final combined inputs pass the core product build,
  relevant normal correctness suite, and the required package/consumer checks
  without repeating unchanged valid tests. Retain exact SHA, commands and
  results; distinguish local, hosted and published evidence.
