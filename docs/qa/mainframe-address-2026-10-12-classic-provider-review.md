# Native Classic runtime dependency amendment

12 October 2026. This is an RXVM and library-delivery amendment to Stage 1.
Native CMS compiled, assembled and linked the full Classic ADDRESS fixture at
RC 0, then RXVM returned -1 before execution because required rxcstream was
absent. The original failure and successful native stages remain evidence.

The owning rxlink `-p` projection over the exact linked Classic/G image requires
the rxcstream transport methods and rxfs.abspath/isfile/loadpath. The native
recipe omitted both providers. The static host control resolves these bindings
and then exposes the separate classlib.rxbin autoload dependency for
data.stringhashmap's factory. Explicitly linking the matching classlib makes
the static canonical-library smoke execute at RC 0. Required-provider and
autoload validation remain enabled; no G module or script assertion is removed.

The amendment selects the existing stream implementation with explicit shared
CLI/embedding initialization, per-VM sessions and one-thread state without TLS
or compiler constructors. Native record FILEs are sequential, may lack an OS
descriptor and have no qualified seek/truncation contract. The native branch
does not call fileno/fstat for them and reports them as non-positionable.
Positional replacement remains unavailable. This is provider loading support,
not full Classic STREAM qualification.

The private native rxfs subset registers exactly the three required signatures.
isfile opens/closes through cREXX's logical-name/binary boundary. Absolute-path
resolution and executable-path discovery signal FAILURE explicitly; they do
not invent POSIX directories or an executable pathname. The desktop provider
and other rxfs operations remain separate. Their native qualification is later
work, outside ADDRESS Stage 1.

Both CMS31 and TSO31 replacement RXVMs pass compile/annotate/assemble/input/image
checks with source hashes unchanged across each build. The selected heap stays
192 MiB. The original RXC/RXAS/RXLINK packages, native Classic object outputs,
four initial libraries, original fixtures and historical receipts are retained.
Guest replay installs only the separately frozen RXVM, stages matching classlib,
and relinks the exact native Classic object with library/rxfnsc/rxfnsg/classlib.
No full compiler replay is necessary for this dependency correction.

Focused host proof uses the actual static port and canonical five-library
collection, plus normal ADDRESS/stream lifetime checks. Full normal and
sanitizer runs on the preceding candidate retain their exact source scope;
the opt-in native amendment needs its own focused sanitizer and guest receipts.
The retained mainframe-classic-pack.crexx freezes the two runtime packages,
before/after build receipts, matching libraries, source/recipe/review and a
reproducible canonical-library smoke and provider projection. Native success
is claimed only after actual guest completion and script assertions.
