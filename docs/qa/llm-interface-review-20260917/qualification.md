# Common LLM drivers: implementation qualification

This is the implementation evidence for [LLM-API-01](../../planning/llm-provider-interface.md).
The neighboring README records the earlier review of `d0feda283` and is historical.
The implementation changes were qualified on macOS arm64 in Debug and the
maintained Apple ASan build. Publication/platform results are recorded below;
this record does not close the parent native-inference plan's open hardware or
release criteria.

## Inputs and local results

[qualified-inputs.json](qualified-inputs.json) records source/test/build SHA-256
values. Model identities/settings and provenance limits are in
[additional-models.json](additional-models.json),
[generation-models.json](generation-models.json) and the checked-in
[text fixture manifest](../../../tests/native-inference/fixtures/text-manifest.json).
The fixture generator reproduced the recorded SHA-256 byte for byte. Both
weights and byte vocabulary are generated independently; no trained tokenizer
or model weights are redistributed.

The final hosted-origin diagnostic correction affects the HTTP library and its
fixture. The final ASan aggregate and standalone fixtures use that corrected
library. Earlier Debug package timing remains valid for the unchanged package
scenarios; the final ASan package also verifies the refreshed library.

New nested aggregates were measured in isolation before registration:
`rxllama_common_drivers` is serial with a 1,800-second hang backstop; expanded
`rxllama_release_package_smoke` remains serial with a 3,600-second backstop.
These limits are hang protection, not performance acceptance.

## Reproduction

```sh
cmake --build cmake-build-debug --parallel 8
cmake --build cmake-build-debug --target qa-prep-comprehensive --parallel 8
ctest --test-dir cmake-build-debug --parallel 30 --output-on-failure \
  --label-regex '^(essential|smoke|comprehensive)$'
cmake --build cmake-build-debug --target rxllama_release_smoke_measure

tools/asan-run.sh --phase build --build-target rxllama_common_prerequisites \
  --build-target ts_llm_http_fixture --build-target rxllama_release_smoke_measure \
  --build-jobs 8 --build-leaks off --no-live-tail
tools/asan-run.sh --phase focused-lsan \
  --regex '^(rxllama_common_drivers|ts_llm_.*|address_llm_provider|interface_factory_signal_restore_run_.*|inline_receiver_signal_cleanup.*|rxpa_native_unwind.*)$' \
  --build-jobs 8 --test-jobs 1 --build-leaks off --leaks off --no-live-tail

python3 tests/native-inference/local_model_compatibility.py \
  --build cmake-build-debug \
  --models /Users/adrian/Library/Caches/crexx/native-inference \
  --output cmake-build-debug/lib/plugins/llama/tests/common-trained \
  --gemma /Users/adrian/Models/gemma4/gemma-4-E4B-it-Q4_0.gguf
```

Model checks require explicitly provisioned files; the harness downloads nothing.
Provisioned converted Stories weights have no model-card/license declaration in
their source repository and are local test inputs only. They are not distributed.

## Publication gates and status authority

All local gates are satisfied. Adrian authorized publication to `origin/develop`
after those checks, followed by the normal automatic workflows. The immutable
check records attached to the revision containing this qualification record are
the publication receipt: **Build CREXX** (including optimizer parity, core smoke,
and combined optional-provider package smoke on Linux, Windows and macOS), and
**CodeQL**. Use the revision's checks from the
[develop history](https://github.com/adesutherland/CREXX/commits/develop/),
[Build runs](https://github.com/adesutherland/CREXX/actions/workflows/build.yml?query=branch%3Adevelop)
and [CodeQL runs](https://github.com/adesutherland/CREXX/actions/workflows/codeql-analysis.yml?query=branch%3Adevelop).
A missing or failed required check leaves LLM-AC-08 / delivery completion open;
terminal success closes those publication criteria for that revision. This
avoids duplicating a moving workflow status as a permanent assertion in a guide.
No additional overnight matrix is required or dispatched for this change.
