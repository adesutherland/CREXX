# PDOS fixture command-vocabulary amendment

12 October 2026. The native PDOS command router qualifies VERSION/ECHO;
PCOMM also offers a VER spelling. The Rexx fixtures accidentally used VER
through ADDRESS PDOS after the contained fault. The CMS execution returns
actual PCOMM END 5 RC=14; the host actor classified its unexpected result as
a console-event watchdog. Its native transcript, child RC7, contained-fault
result and normal shutdown are preserved. This is a fixture vocabulary error,
not heap exhaustion or a reason to change the production router.

The maintained bounded CMS fixtures now use VERSION for recovery. Two separate
TSO-personality fixtures preserve the original native script checks and also
use VERSION through ADDRESS PDOS. Original native CMS/TSO source, frozen pack,
compiled/assembled outputs and receipts remain unchanged. Current qualified
PDOS fixtures have a separately frozen copy and syntax/assembly proof over
the canonical library collection. The previous CMS fixture copies and failed
run remain historical evidence; their source hashes are not asserted current.

Capture, nonzero results, contained fault, later selected-native command,
caller file with a 64 KiB tail, wide guard, Classic RC/.RC/.RS and condition
handler checks remain required. No assertion is removed to make a run pass.
The new retained mainframe-pdos-qa-pack.crexx records the source/copy/host
bytecode/tool identities and the runtime-provider amendment manifest.
Actual native compile/assemble/link/execute on both disposable personalities
remains the guest acceptance gate.
