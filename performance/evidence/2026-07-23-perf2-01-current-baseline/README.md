## Limitations and rejected diagnostics

- Base64 cREXX timing and NetRexx Richards timing retain their noise labels
  after the single governed append; no passing sample was removed.
- Apple hardware event counters were unavailable, so cycles, native
  instructions, branch misses, i-cache and iTLB events are absent. Statistical
  samples and explicit opcode timing remain diagnostic only.
- The focused AddressSanitizer build and accounting test pass. Apple
  AddressSanitizer rejects `detect_leaks=1` as unsupported on this platform, so
  the same supported-runner test was completed with ASan active and leak
  detection off; both the platform rejection and accepted rerun are retained.
- Selector cache/site data is not exercised: all accepted optimized profiles
  report zero current selector attempts. No cache result was fabricated.
- The initial rxvm profile manifest had a stale JSON image hash and stopped
  before that entry. The invalid partial is represented by
  `input-manifest.pre-resume.txt`; the corrected exact hash was validated before
  resume. No invalid JSON profile entered summaries.
- The initial common-matrix append manifest mislabelled the append cells as
  aggregate members. Raw samples were correct; the retained repair note and
  cREXX regeneration make the combined membership exact.
- The first final focused CTest omitted two sequence prerequisites. Its retained
  log shows only missing artifacts; after exact prerequisite builds, the same
  17 tests passed. The initial Mandelbrot native sample and Bounce lite heap
  command are likewise retained and explicitly rejected in their lane READMEs.
