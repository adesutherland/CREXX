## Reproduction

```sh
experiments/unicode/poc/run.sh
```

The command checks fixture hashes, builds only the standalone vendored re2c,
regenerates the reference source with date/version/line metadata suppressed,
compares it byte-for-byte with the committed output, compiles it, proves that
wrong-version and malformed rules fail with line diagnostics, runs the complete
applicable NFD corpus, and compares the summary with
`evidence/nfd-conformance.txt`.

## Passing Result

- 403 canonical-combining-class rule records covering 968 code points parsed;
- 961 two-way and 1,120 one-way canonical mappings parsed;
- 20,034 normalization rows across Parts 0 through 5;
- 100,170 NFD corpus relations passed;
- 1,094,978 scalar values absent from Part 1 proved to be NFD identities; and
- committed generated C++ matched fresh output byte-for-byte.

The 1,094,978 identity checks include unassigned scalar values as a deliberate
strengthening of UAX #15's required assigned-code-point check. Surrogate code
points are excluded because they are not Unicode scalar values.

## Qualification Boundary

The proof demonstrates a faithful re2c reader for the selected ICU `gennorm2`
surface plus conformant NFD semantics in a C++ oracle. It does not yet prove:

- NFC, NFKD, NFKC, case folding, comparison, or text segmentation;
- UTF-8 streaming/error APIs (the conformance corpus is hexadecimal scalar
  data);
- a CREXX-native Level L rule syntax or generator;
- a portable or host-native packed Unicode table layout;
- Level G APIs, either VM, supported-platform parity, sanitizer gates, install,
  or package behavior.
